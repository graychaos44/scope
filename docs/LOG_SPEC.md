# 로그에서 뽑을 것 — 기본부터, 계속 추가 (2026-08-13 신설)

> 사용자 08-13: *"다음부터는 로그를 잘 만들게 해. **처음부터 완벽한 건 없으니까**
>  일단 로그에 뭘 추출할지 **기본적인 것들 뽑고 나중에 계속 추가**하자."*

이 문서가 **무엇을 남기고 있는지의 정본**이다. 항목을 늘릴 때 여기부터 고친다.

---

## 원칙 셋

1. **요약과 원자료를 같이 남긴다.** 요약만 남기면 새 질문이 생길 때마다 다시 돌려야 한다.
2. **항목 수에 상한을 두지 않는다.** 늘리려면 표에 열을 추가하면 되고, 옛 기록은 그대로 읽힌다.
3. **못 남긴 것은 여기 '아직 없음' 에 적는다.** 안 적으면 없다는 사실 자체를 잊는다.

## 지금 남는 것 (2026-08-13)

기록 한 건 = `runs/<run_id>/` 폴더 하나.

| 파일 | 무엇이 | 줄 수 |
|---|---|---|
| `run.json` | 조건·지표·산출물·시각·기기·git | 1 |
| `판별.tsv` | **판 하나에 한 줄** | 판 수만큼 |
| `회차별.tsv` | **학습 회차 하나에 한 줄** | 회차 수만큼 |
| `SCOPE_LEDGER.tsv` | 실행 전체의 한 줄 색인 | 실행마다 1 |

### `판별.tsv` 열

| 열 | 뜻 |
|---|---|
| 판 · 회차 · env | 몇 번째 판인지 · 어느 학습 회차 중 · 몇 번 게임에서 |
| 보상 | 그 판의 보상 합 |
| **통과** | 스테이지를 깼나 (★진짜 성공 지표) |
| 죽음 | 죽어서 끝났나 (아니면 시간초과) |
| 처치 | 적을 몇 마리 |
| **출구까지최소칸** | 그 판에서 출구에 가장 가까웠던 거리 |
| 수 | 판 길이 |
| 끝체력 | 끝났을 때 체력 |

### `회차별.tsv` 열

| 열 | 뜻 |
|---|---|
| 회차 · loss | 학습 회차와 손실 |
| 판누적 · 통과누적 | 지금까지 몇 판 / 몇 번 통과 |
| **코어내재보상** | 코어의 보상 담당(RND)이 스스로 만든 점수의 평균 |
| 평균보상20 | 최근 20판 평균 |

### `run.json` 지표

| 이름 | 단위 |
|---|---|
| `train.updates` · `train.env_steps` · `train.episodes` | count |
| `result.ep_return_mean20` · `result.ep_return_best` | reward |
| **`result.wins`** | count |
| `result.exit_dist_best` · `result.exit_dist_mean20` | cells |
| **`policy.action_share.<버튼>`** | percent_0_100 |

★`policy.action_share` 는 넣자마자 값을 했다 — *"길잡이를 5%밖에 안 쓴다"* 가 바로 보였고
그것이 학습이 안 되던 이유였다(V743). **버튼 비율은 항상 남긴다.**

## 아직 없음 (다음에 추가할 것)

| 항목 | 왜 필요한가 | 언제 |

| 판 안의 **수별 기록**(좌표·체력·버튼) | "어디서 막혔나" 를 판 하나로 되짚기 | 판이 길어 용량 크다 — 표본 판만 남기는 방식으로 |

| 체크포인트 **해시** | 어느 기록이 어느 가중치인지 확실히 | 다음 |
